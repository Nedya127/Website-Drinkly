# Website Drinkly

Website Drinkly adalah proyek website minuman yang dibuat menggunakan React dan Vite.

## Teknologi
- React
- Vite
- JavaScript
- CSS

## Daftar Komponen dan Props

### WebsiteDrinkly
File: `src/components/WebsiteDrinkly.jsx`

Komponen ini menampilkan informasi nama, peran, tahun, dan status.

Props yang digunakan:
- `nama`: nama yang ditampilkan.
- `peran`: peran pengguna.
- `tahun`: tahun yang ditampilkan.
- `aktif`: menentukan status aktif atau tidak aktif.

## Menjalankan Proyek

1. Clone repository:
   `git clone https://github.com/Nedya127/Website-Drinkly.git`
2. Masuk ke folder proyek:
   `cd Website-Drinkly`
3. Instal dependensi:
   `npm install`
4. Jalankan aplikasi:
   `npm run dev`
5. Buka alamat lokal yang ditampilkan di terminal.
